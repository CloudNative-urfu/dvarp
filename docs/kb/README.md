# База знаний для агентов (kb/)

Структурированный слой документации DVARP: требования, формулы, контракты,
референсы. Единственный источник правды по канону исследования. Человеко-читаемые
документы лежат уровнем выше (`docs/`) и каноном не являются.

## Карта

| Документ | Назначение |
| --- | --- |
| `glossary.md` | Термины и канонные определения; связь с FR/NFR и фабрикой |
| `guardrails_requirements.md` | Требования полигона FR-1.x / NFR-2.x; «Отклонения канона» — ревизии решений с датами |
| `guardrails-research-design.md` | Спецификация полигона: схема, конфигурации, метрики, экономическая модель, У1–У4, прогон-микс, граница телеметрия/расчёт, контракт СС↔полигон |
| `guardrails-break-even.md` | Модель окупаемости: разложение ΔNet, порог `L*` |
| `guardrails-research-risks.md` | Реестр рисков, формальный аппарат, pre-registration, чек-листы |
| `methodology/` | Разборы методологий чужих работ с цитатами; `methodology/README.md` — навигация |
| `landscape/` | Справочник реальных прод-процессов поддержки |
| `research-cycles/` | Кампании фабрики: циклы 1–9, сводка, сырые проверенные данные |

## Правила работы для агентов

1. Канон — состояние ветки `research`; правки канона через PR с записью в
   «Отклонениях канона» (`guardrails_requirements.md`).
2. Механики прототипа (СС) — в репозитории `dvarp-prototype`, каталог
   `docs/manuals/` («трейс для полигона»); этот слой встраивается в базу знаний
   по ссылке, а не копированием.
3. Человеко-читаемые документы (`docs/` выше) — не источник требований;
   ссылаемся на них при необходимости дать контекст человеку, но формулы и
   правила берём здесь.
