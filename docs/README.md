# Документация DVARP

Документы в корне `docs/` знакомят читателя с исследованием. В `docs/kb/` собраны
формулы, контракты, протоколы и справочные материалы для агентов. Глоссарий и
требования служат общим источником определений и правил. Разделение принято
14 ноября 2026 года в рамках задачи #24.

Обзорные документы отсылают к номерам требований и разделам канона. Требования и
история их изменений приведены в `guardrails_requirements.md`, включая раздел
«Отклонения канона». Формальные спецификации находятся в `docs/kb/`. Агенты также
используют записи о работе полигона из `docs/manuals/` в репозитории `dvarp-prototype`.

| Документ | Содержание |

## Как вносятся изменения

В обзорных документах можно уточнять объяснения и ссылки. Изменения канона
оформляются через раздел «Отклонения канона» в `guardrails_requirements.md` и PR
в `research`.
