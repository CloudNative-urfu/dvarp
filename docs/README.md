# Документация DVARP

Документация репозитория разделена на два слоя по назначению. Разделение
оформлено решением 2026-11-14 (issue #24): человеко-читаемые документы описывают
исследование языком для людей; база знаний для агентов содержит структурированный
канон — требования, формулы, контракты и референсы, из которых агенты работают.

Правило слоёв: канон исследования живёт в `kb/`; человеко-читаемые документы
ссылаются на канон текстом (номера FR/NFR, разделы), а не дублируют его. Для
агентов: не опираться на человеко-читаемые документы как на источник требований —
источник требований и формул здесь (`docs/kb/`) и трейс полигона в репозитории
`dvarp-prototype` (`docs/manuals/`).

## Человекочитаемые документы (`docs/`)

Для ознакомления с исследованием: нарратив, обоснования, обзоры. Перерабатываются
вручную; до окончания переработки могут содержать справочные конструкции.

| Документ | Содержание |
| --- | --- |
| `guardrails-as-a-vector-of-attack.md` | Главная рамка исследования: гипотеза «защита как вектор атаки», схема, цели, границы. Входная точка для человека |
| `guardrails-usp.md` | Уникальность и новизна исследования: за счёт чего работа отличается от существующих |
| `guardrails-target-audience.md` | Адресаты исследования: сегменты аудитории, их потребности и боли |
| `guardrails-literature-review.md` | Обзор литературы: ближайшие работы и пустота, которую занимает исследование |
| `paper/draft.md` | Черновик научной статьи — высшая человекочитаемая форма результатов |

## Статус переработки

Человеко-читаемые документы перерабатываются вручную (цель: ноль машинных
конструкций при полном покрытии сути исследования). База знаний `kb/` канонична
и переработке под нарратив не подлежит. Правки канона оформляются через
«Отклонения канона» (`kb/guardrails_requirements.md`) и PR в `research`.
