## Проверяемый пример и чувствительность

Синтетический пример по [формуле окупаемости](kb/guardrails-break-even.md#92-порог-окупаемости). Дельты затрат считаются относительно g0.

| Вход | Значение |
| --- | ---: |
| `w_A / w_L` | 0.05 / 0.95 |
| `V(g0) − V(g)` | 0.10 |
| `ΔR` | 0.02 |
| `ΔQ` (минут на легальный эпизод) | 0.20 |
| `Δ[E_L · P(W_q > Q_SLA)]` | 0.01 |
| `ΔE` | 0.04 |
| Дополнительные вызовы на атакующий эпизод для `ΔC_ep` | 1 |
| Вызовы гвардрейла на входящий эпизод для `C_guard` | 1 |

При одной цене вызова p для обоих компонентов:

```text
L* = (0.019*C_refuse + 0.19*C_queue + 0.0095*c_sla + 0.04*C_manual + 1.05*p) / 0.005
```

При изменении одной цены остальные сохраняются на базовом уровне. L* — в USD за исполненное нарушение.

| Изменяемая цена | L* при min | L* при base | L* при max |
| --- | ---: | ---: | ---: |
| `C_refuse` | 20.34 | 21.10 | 23.95 |
| `C_queue` | 17.30 | 21.10 | 30.03 |
| `c_sla` | 20.63 | 21.10 | 22.53 |
| `C_manual` | 11.74 | 21.10 | 42.94 |
| Арендованный инференс `p` | 20.94 | 21.10 | 21.93 |
| Все цены одновременно | 6.54 | 21.10 | 56.97 |

В этом примере порог сильнее всего зависит от цены ручного разбора и ожидания. При ущербе 40 USD базовый сценарий окупается. В сценарии высоких затрат порог составляет 56.97 USD. При цене API 0.00022 USD за вызов базовый порог составляет 20.87 USD. Равенство ущерба и порога даёт нулевой эффект. Для реального прогона границы совместного сценария необходимо определять с учётом знака каждой дельты.

При нулевом знаменателе конечного порога нет.

## Подстановка в расчётчик

Четыре цены из выбранного столбца необходимо передать в `Prices(C_refuse=…, C_queue=…, C_sla=…, C_manual=…)`; `C_queue` задаётся в USD за минуту. CLI принимает ущерб через `--l-viol 10,40,150`, а пользовательские цены задаются через Python.
Стоимость для `C_ep` и `C_guard` необходимо рассчитывать по журналу. Стоимость API рассчитывается по отдельным ставкам для входных и выходных токенов, стоимость аренды — по оплаченным GPU-часам с учётом простоя. Один и тот же вызов учитывается один раз.
